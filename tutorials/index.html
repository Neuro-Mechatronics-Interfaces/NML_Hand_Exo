    Tutorials

    Follow these focused walkthroughs to go from flash → motion → control. For a card-style gallery, you can also create tutorials/index.md using the splash layout.

    Available Tutorials

    1) First Motion

    Flash firmware, home axes, and execute your first gesture.
    Start: /tutorials/first-motion/

    2) Live EMG Classification

    Stream 250 ms EMG windows and classify in real time (Intan/Open Ephys).
    Start: /tutorials/live-emg/

    3) ROS2 Teleop (coming soon)

    Joystick control with collision checks using MoveIt.
    Planned path: /tutorials/ros2-teleop/

    4) Force Plate Calibration (coming soon)

    Zero, span, and verify using reference weights.
    Planned path: /tutorials/force-plate/
