NML Hand Exoskeleton documentation
===================================

The NML Hand Exoskeleton repository contains the Python SDK, operator and EMG
applications, OpenRB-150 firmware, and optional CircuitPython TCP bridge.

.. warning::

   This is research software for supervised laboratory use. Confirm the active
   calibration profile, current limits, joint limits, motor IDs, and emergency
   stop before participant use.
