Detailed Description

Implementation file for the NML Hand Exoskeleton API.

This file contains the implementation of the NMLHandExo class, which handles initialization, motor control, angle management, and device telemetry for the exoskeleton.

uint8_t gReplyRoute = REPLY_ROUTE_BOTH

Reply/telemetry routing for dual-CDC. Legacy-safe default (BOTH).

Where command replies / telemetry are emitted (dual-CDC). One of REPLY_ROUTE_BOTH / REPLY_ROUTE_TELEM / REPLY_ROUTE_CMD (see config.h). Default REPLY_ROUTE_BOTH keeps legacy single-port hosts working.
