326 // -----------------------------------------------------------
327 // Gesture fractional axis
328 // -----------------------------------------------------------
329 //
330 // Every gesture percentage -- the EXTEND_*/REST_*/FLEX_* constants,
331 // `set_gesture_angle`, `get_gesture_angle` -- rides on ONE per-motor axis:
332 // 0 at home, 1 at the flexion endstop. Defining it in one place is what
333 // makes those three agree, and what makes the mapping invertible so a
334 // measured angle can be reported back as the percentage that produced it.
335 //
336 // The old form scaled by the whole window width (limit_max - limit_min) and
337 // took its direction solely from the flip flag, which assumed home sat on
338 // the extension endstop. Where it did not -- the wrist and wrist2 axes --
339 // every state landed past the boundary, setAbsoluteAngle() clamped them all
340 // to the same angle, and the joint stopped moving while still acking OK.
