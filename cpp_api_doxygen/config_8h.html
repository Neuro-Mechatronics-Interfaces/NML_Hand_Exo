◆ MOTOR_CURRENT_LIMIT

constexpr int MOTOR_CURRENT_LIMIT = 910
constexpr

Current limit for XC330-T288 motors.

ROBOTIS documents Current Limit(38) for the XC330-T288 as 0-910 units, about 1 mA per unit. This project uses the full documented range because participant finger spasticity can require higher assistive torque.

◆ XC330_T288_TORQUE_CONSTANT

constexpr float XC330_T288_TORQUE_CONSTANT = 0.00115f
constexpr

Estimated torque constant for XC330-T288 servos, in N*m/mA.

Based on ROBOTIS stall torque/current at the recommended 11.1 V supply: 0.92 N*m / 0.80 A = 0.00115 N*m/mA. XC330 current telemetry is measured at the input power source, so displayed torque should be treated as an estimate.
